1 配置指令

1.1 惯导使能配置

   UM981模块惯导器件默认处于开启状态。用户可使用CONFIG INS DISABLE指令关闭

惯导器件；若要再次开启惯导功能，需输入CONFIG INS RESET使能INS并复位到未对准状

态。

   命令格式为：

   CONFIG INS [参数]

   命令示例：

   CONFIG INS DISABLE

指令头       设备            参数        参数描述
                        Disable   关闭惯导
CONFIG    INS
                        Reset     开启惯导并复位到未对准状态

1.5 IMU 至主天线杆臂参数配置

   此命令输入IMU和GNSS主天线相位中心之间的偏移量，即惯导至主天线杆臂参数。x、

y和z代表IMU到主天线相位中心的矢量。a、b和c字段用于输入测量中的可能的误差。例如，

如果“X”偏移测量精度为1厘米，则在“a”字段中输入0.01。

   测量杆臂参数时应尽可能精确，以提升组合结果的性能。

   命令格式：

   CONFIG IMUTOANT OFFSET x y z [a] [b] [c]

   命令示例：

   CONFIG IMUTOANT OFFSET 0.54 0.32 1.20 0.03 0.03 0.05

   此命令用于配置INS初始航向角及其STD，使得INS能够在静态下完成对准初始化。此

时对准后的精度不高，在载体运动一段时间后，INS的精度才会逐渐收敛提升。


    此命令不支持保存。
   命令格式：

   CONFIG INS AZIMUTH azimuth azSTD

   CONFIG INS AZIMUTH 90 5

   在以上例子中，初始航向角被设置为90度。这意味着定位模块的Y轴指向东，在5度的

标准偏差内。

1.8 INS 初始姿态角及 std 配置

   此命令用于配置INS的初始姿态角及STD，使用此命令使得INS立即对准而不再需要动

态对准过程。此时对准后的精度不高，在载体运动一段时间后，INS的精度才会逐渐收敛

提升。

   下面列出了这个命令的注意事项和特殊条件：

   1、这种对准是用户即时输入的，这一命令会使系统更快地启动进入导航模式，输入值

尽量是准确的，否则将影响系统性能。

   2、如果不确定输入的角度精度，请增大输入的角度std值。


    此命令不支持保存。
   命令格式：

   CONFIG INS ATTITUDE pitch roll azimuth pitchSTD rollSTD azSTD

   命令示例：

   CONFIG INS ATTITUDE 0 0 90 5 5 5

   在以上例子中，初始俯仰角和横滚角被设置为0度，初始航向角被设置为90度，标准

差为5度。这意味着模块基本水平放置，Y轴指向东，在5度的标准偏差内。

     header部分有两种格式，即normal型header和short型header，见上节说明。

     对于一条MSG，最多有四种输出格式：

     1)     XXXA表示输出normal header、ASCII格式的数据；

     2)     XXXB表示输出normal header、BINARY格式的数据；

     3)     XXXSA表示输出short header、ASCII格式的数据；

     4)     XXXSB表示输出short header、BINARY格式的数据。
