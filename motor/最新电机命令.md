# 📡 串口通信协议文档 V2.0

> 本文档由 `最新电机命令.xlsx` 整理而成，覆盖原工作簿的全部协议内容。
>
> **校验说明：** 原工作簿中的“差速控制”和“状态返回帧”存在校验和计算错误。本文正文使用按照协议公式复算后的正确值，并在文末保留原值及修正对照。

## 一、协议基本格式

| 字节序号 | 名称 | 长度 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| Byte0 | 帧头 | 1 字节 | 固定为 `0xAA` | `AA` |
| Byte1 | 长度 | 1 字节 | 功能码与数据的总字节数 | `01` |
| Byte2 | 功能码 | 1 字节 | 命令码，参见“命令码表” | `01` |
| Byte3... | 数据 | N 字节 | 可选，具体长度由命令决定 | `32 1E` |
| Byte N+3 | 校验和 | 1 字节 | 从帧头到数据结束的累加和，取低 8 位 | `AC` |
| Byte N+4 | 帧尾 | 1 字节 | 固定为 `0x55` | `55` |

完整格式：

```text
[帧头] [长度] [功能码] [数据...] [校验和] [帧尾]
```

即：

```text
AA LEN CMD DATA... CHECKSUM 55
```

## 二、长度字段计算规则

```text
长度 = 功能码长度（1 字节）+ 数据字节数
```

| 命令类型 | 功能码长度 | 数据字节数 | 长度值 |
| --- | ---: | ---: | ---: |
| 无数据命令 | 1 | 0 | `0x01` |
| 单数据命令 | 1 | 1 | `0x02` |
| 双数据命令 | 1 | 2 | `0x03` |

示例：

- 前进命令：功能码 1 字节 + 数据 0 字节，长度为 `0x01`。
- 设置速度：功能码 1 字节 + 数据 1 字节，长度为 `0x02`。
- 差速控制：功能码 1 字节 + 数据 2 字节，长度为 `0x03`。

## 三、校验和计算规则

校验和是从帧头 Byte0 到最后一个数据字节的累加和，并取结果的低 8 位。帧尾不参与计算。

```text
校验和 = (帧头 + 长度 + 功能码 + 所有数据字节) & 0xFF
```

### 示例 1：前进命令

```text
帧头：   AA
长度：   01
功能码： 01
数据：   无

累加和 = AA + 01 + 01 = AC
校验和 = AC

完整帧：AA 01 01 AC 55
```

### 示例 2：设置速度为 80%

```text
帧头：   AA
长度：   02
功能码： 0A
数据：   50

累加和 = AA + 02 + 0A + 50 = 0x106
取低 8 位 = 06
校验和 = 06

完整帧：AA 02 0A 50 06 55
```

### 示例 3：差速控制，左轮 50%、右轮 30%

```text
帧头：   AA
长度：   03
功能码： 09
数据 1： 32（左轮 50%）
数据 2： 1E（右轮 30%）

累加和 = AA + 03 + 09 + 32 + 1E = 0x106
取低 8 位 = 06
校验和 = 06

完整帧：AA 03 09 32 1E 06 55
```

## 四、命令码表

| 功能 | 功能码 | 数据 | 完整 HEX 帧 | 说明 |
| --- | --- | --- | --- | --- |
| 前进 | `0x01` | 无 | `AA 01 01 AC 55` | 以当前速度前进 |
| 后退 | `0x02` | 无 | `AA 01 02 AD 55` | 以当前速度后退 |
| 停止 | `0x03` | 无 | `AA 01 03 AE 55` | 滑行停止 |
| 制动 | `0x04` | 无 | `AA 01 04 AF 55` | 紧急刹车 |
| 左弧线转弯 | `0x05` | 无 | `AA 01 05 B0 55` | 左轮慢、右轮快 |
| 右弧线转弯 | `0x06` | 无 | `AA 01 06 B1 55` | 左轮快、右轮慢 |
| 左原地转弯 | `0x07` | 无 | `AA 01 07 B2 55` | 左轮反转、右轮正转 |
| 右原地转弯 | `0x08` | 无 | `AA 01 08 B3 55` | 左轮正转、右轮反转 |
| 差速控制 | `0x09` | 左轮速度、右轮速度 | `AA 03 09 32 1E 06 55` | 示例为左轮 50%、右轮 30% |
| 设置速度 | `0x0A` | 速度值 | `AA 02 0A 50 06 55` | 示例为设置默认速度 80% |
| 获取状态 | `0x0B` | 无 | `AA 01 0B B6 55` | 请求返回当前速度 |
| 紧急停止 | `0xFF` | 无 | `AA 01 FF AA 55` | 紧急刹车并将速度归零 |

### 可变参数命令模板

设置默认速度，其中 `SS` 为 `00`～`64` 的速度值：

```text
AA 02 0A SS CHECKSUM 55
CHECKSUM = (AA + 02 + 0A + SS) & FF
```

差速控制，其中 `LL`、`RR` 分别为左轮和右轮速度：

```text
AA 03 09 LL RR CHECKSUM 55
CHECKSUM = (AA + 03 + 09 + LL + RR) & FF
```

## 五、速度值对照表

速度数据以百分比的数值直接编码，工作簿列出的常用值如下：

| 十进制 | 十六进制 | 说明 |
| ---: | ---: | --- |
| 0 | `0x00` | 停止 |
| 30 | `0x1E` | 30% 速度 |
| 50 | `0x32` | 50% 速度 |
| 60 | `0x3C` | 60% 速度 |
| 80 | `0x50` | 80% 速度 |
| 100 | `0x64` | 100% 速度 |

## 六、状态返回帧

发送获取状态命令：

```text
AA 01 0B B6 55
```

返回帧中的功能码为 `0x0B`，后跟一个当前速度数据字节：

```text
AA 02 0B SPEED CHECKSUM 55
```

| 场景 | 正确返回 HEX | 说明 |
| --- | --- | --- |
| 当前速度 50% | `AA 02 0B 32 E9 55` | 速度数据为 `0x32`，校验和为 `0xE9` |
| 当前速度 80% | `AA 02 0B 50 07 55` | 速度数据为 `0x50`，校验和为 `0x07` |
| 当前速度 100% | `AA 02 0B 64 1B 55` | 速度数据为 `0x64`，校验和为 `0x1B` |

以当前速度 80% 为例：

```text
AA + 02 + 0B + 50 = 0x107
取低 8 位 = 07

完整返回帧：AA 02 0B 50 07 55
```

## 七、完整帧结构图

### 前进命令

```text
完整帧：AA 01 01 AC 55

Byte0：AA  帧头
Byte1：01  长度，1 字节功能码
Byte2：01  功能码，前进
Byte3：AC  校验和，AA + 01 + 01
Byte4：55  帧尾
```

### 差速控制

```text
完整帧：AA 03 09 32 1E 06 55

Byte0：AA  帧头
Byte1：03  长度，1 字节功能码 + 2 字节数据
Byte2：09  功能码，差速控制
Byte3：32  数据 1，左轮 50%
Byte4：1E  数据 2，右轮 30%
Byte5：06  校验和
Byte6：55  帧尾
```

## 十、原文档未提供的串口参数

工作簿没有规定以下内容，实现串口程序前需要向控制器固件或设备厂家确认：

- 波特率；
- 数据位、停止位和奇偶校验；
- 串口流控方式；
- 命令响应超时与重试规则；
- ACK/NACK、错误响应或异常码；
- 连续命令的最小发送间隔；
- 差速控制速度字节是否只表示大小，以及方向如何组合控制。
